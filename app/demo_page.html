About this demo

An ElevenLabs voice agent with deterministic business logic.

Inbound commercial real estate leads in the Toluca metropolitan area, Mexico, often wait hours for a first response. Eliza answers instantly, qualifies the lead in Spanish, and hands it to the sales team as a structured, scored record in Notion.

How it works

  1. Conversation. An ElevenLabs agent with a Spanish system prompt asks one question at a time, offers budget ranges when the caller is unsure, and confirms the details back.
  2. Server tool. After confirmation it calls save_lead, an authenticated FastAPI webhook. Conversation ID and caller ID come from dynamic variables, never from the model.
  3. Deterministic logic. Pydantic validates the payload, plain Python scores the lead and computes the callback time from business hours, then the lead is written to Notion.
  4. Close. The tool response tells the agent exactly when a person will call, so it never promises a time the team can't keep.
